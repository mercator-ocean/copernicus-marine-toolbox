Release 2.6.0
=============

This release introduces new features and improvements.

General
-------

New Features
^^^^^^^^^^^^

* Drop support for Python 3.10. The minimum supported Python version is now 3.11.
* Added an environment variable ``COPERNICUSMARINE_MAX_POOL_CONNECTIONS`` to set the maximum number of connections in the connection pool for HTTP requests. Default is ``10``.

Subset
------

New Features
^^^^^^^^^^^^

* Added a missing feature for sparse datasets. Sparse datasets can now be subsetted by specifying the standard names of the variables.
